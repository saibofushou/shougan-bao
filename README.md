# 游戏手感包

这是一套**交给 AI 就能照着做出来**的游戏手感规范。每一条都在我们自己的视频和小例子里做出来、调过，写的是**具体数值**，不只是道理。

免费开源，来自抖音「赛博福寿无量」的游戏拆解视频。
【至于代码中的中文，请忽略，我也是进行到一半发现的，再重编码性价比低了，反正你自己不看,ai又肯定能懂。】

**下载**：点这一页上方绿色的「Code」按钮 →「Download ZIP」，解压就能用。不用注册，不用装任何软件。

## 怎么用（三步）
1. 找到你要的模块，打开那一页（`.md`）。
2. 把页里「**交给 AI 时这样说**」那一段整段复制给 AI（Claude、ChatGPT、Cursor 都行）。想让它写得更准，把同名的小例子（`例子/xx.html`）一起发给它，说「照这个例子的做法，接进我的游戏」。
3. AI 做完，用页末的「**验收清单**」一条条对。哪条不对，就把那条原样发给 AI 让它改。

小例子不用装任何东西：**双击 `例子/` 里的 html 文件，用浏览器打开就能玩**。每个例子顶上都有一张「参数表」，改数字、刷新页面就能看到变化。左边的开关可以一招一招地开、关，对比着看。

## 约定
- 时间默认按**每秒 30 帧**写；你的游戏是 60 帧，帧数就乘 2。写「秒」的不用换算。
- 颜色写成网页颜色（如 `#ffd23c`），哪个引擎都能用。
- 每个模块的结构都一样：一句话规矩 → 清单（做什么 / 数值 / 为什么）→ 常见错误 → 交给 AI 时这样说 → 验收清单 → 出处（我们哪几条视频）。
